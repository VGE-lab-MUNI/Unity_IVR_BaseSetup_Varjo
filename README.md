# Unity IVR Base Setup (Varjo)



Reusable, continuously updated Unity IVR project foundation for Varjo devices (primarily Varjo XR-4).







## Unity Version



Unity 6.x (currently 6000.3.11f1 LTS)







## Purpose



This repository serves as a reusable starting point for Unity IVR projects (for Varjo devices).

The idea of this project is to minimize or eliminate the effort required to set up the base packages and settings when creating a new Unity IVR project, so the user can start developing right away without needing to set everything up themselves.







## Packages Included



\- Unity Input System

\- XR Interaction Toolkit

\- XR Plugin Management

\- Varjo XR Plugin (external)







## Getting Started



1\) Clone this repository.

2\) Check the most recent/relevant commit.

3\) Ready to use.
